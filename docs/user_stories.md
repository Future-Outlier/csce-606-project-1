happy paths:
As a user I want to draw up to three random, unique cards so that I can do a tarot reading.
As a user I want to reset my drawn cards and shuffle the deck so I can do another reading.
As a repeat user I want to review my saved readings so that I can ponder their meanings.
As a repeat user I want to see the date/time of my saved readings so that I can reflect on my history of readings.
As a user I want to view art of the cards so that I can visualize them.
As a user I want to read detailed descriptions of the cards so that I can consider their meanings.

sad paths:
As a user I want to be prevented from saving empty readings so I can keep my record tidy.
As a user I want to be notified if I try to review but there are no readings so I can be confident that the system is working as intended.
As a user I want to be notified if I try to view details of an invalid card so I can correct my input.
As a user I want to be notified if I try to view the art of an invalid card so I can correct my input.
